🔧 Fix Missed Predictions — One-Time Tool

This tool reads your Firebase database, identifies predictions that were made after match lock time, and marks them as missed:true so they don't score points. Place this file in the same folder as your other PSL files and open it in your browser.

Steps

1Click Scan Database to fetch all users and analyse their predictions.
2Review the findings below — every prediction that will be flagged is shown.
3Click Apply Fix to write the missed:true flags to Firebase. Leaderboard will update automatically.
