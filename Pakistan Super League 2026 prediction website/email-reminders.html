EMAIL REMINDERS

Send match reminder emails to all users who have added their email address. Uses EmailJS (free, no server needed).

📌 One-time setup required:

1. Go to emailjs.com → create a free account
2. Add an Email Service (e.g. Gmail) → note the Service ID
3. Create an Email Template with these variables:
   • {{to_email}} — recipient
   • {{to_name}} — username
   • {{match_title}} — e.g. "Lahore Qalandars vs Hyderabad Kingsmen"
   • {{match_date}} — e.g. "Mar 26, 7:00 PM PKT"
   • {{match_venue}} — venue
   • {{has_predicted}} — "YES ✅" or "NOT YET ⚠️"
4. Note your Public Key, Service ID, and Template ID
5. Enter them below and save
