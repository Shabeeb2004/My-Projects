# Property Rental Business Intelligence System

A comprehensive data warehouse and business intelligence solution designed for analyzing property rental business metrics, performance, and insights. This project demonstrates enterprise-level database design, ETL processes, OLAP/MOLAP analytics, and interactive Power BI dashboards.

## 📋 Project Overview

This system enables property rental businesses to:
- Centralize rental data into a structured data warehouse
- Perform advanced analytics on occupancy, revenue, and property performance
- Generate real-time insights through interactive dashboards
- Optimize database performance with indexing and partitioning strategies
- Execute complex analytical queries using OLAP and MOLAP approaches

## 🗄️ Core Components

### Database Architecture
- **Schema Design**: Normalized relational schema with dimensional modeling for analytics
- **Tables**: Properties, Tenants, Rentals, Payments, Maintenance, Reviews
- **Relationships**: Properly structured foreign keys and constraints for data integrity

### ETL & Data Processing
- **Extract**: Source data from rental management systems
- **Transform**: Data cleaning, aggregation, and transformation logic
- **Load**: Efficient data loading into warehouse tables with partitioning

### Advanced Analytics
- **OLAP (Online Analytical Processing)**: Multi-dimensional analysis with SQL queries
- **MOLAP (Multidimensional Online Analytical Processing)**: Aggregated data cubes for faster reporting
- **Performance Optimization**: Advanced SQL joins, indexing strategies, and query tuning

### Business Intelligence
- **Power BI Dashboard**: Interactive visualizations of key metrics
- **KPIs**: Occupancy rates, rental revenue, tenant retention, maintenance costs
- **Reports**: Detailed insights on property performance and business trends

## 📊 Key Metrics & Insights
- Total rental revenue and occupancy rates
- Property-wise performance analysis
- Tenant demographics and retention patterns
- Maintenance cost tracking and optimization
- Seasonal trends and forecasting

## 🛠️ Technologies Used
- **Database**: SQL Server
- **ETL**: SQL-based transformation scripts
- **Analytics**: Advanced SQL (OLAP/MOLAP)
- **BI Tool**: Microsoft Power BI
- **Optimization**: Indexing, Partitioning, and Query Optimization

This system provides rental businesses with actionable intelligence to optimize pricing strategies, improve operational efficiency, and make data-driven business decisions.
