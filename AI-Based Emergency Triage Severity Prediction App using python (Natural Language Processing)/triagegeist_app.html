About Triagegeist

Triagegeist is a machine learning project for the AI in Healthcare module. Six classifiers were trained and compared — Logistic Regression, Decision Tree, Random Forest, Gradient Boosting, XGBoost, and LightGBM — achieving up to 97% F1 Macro on validation data. This demo uses the same deterministic scoring logic as the training pipeline.

🏆 Best Model

LightGBM / XGBoost tied at ~97% F1 Macro with 5-fold stratified cross-validation.

⚙️ Feature Engineering

Shock index, pulse pressure, fever flag, and hypoxia flag added as clinically-derived composite features.

📊 Evaluation

Primary metric: F1 Macro (handles class imbalance). Also reports accuracy, precision, recall, confusion matrix.
